# Boss Highscore

RuneLite plugin. The official hiscores have no total boss kill count, so this adds it up.

- Side panel: search a player for their total boss kills
- Friends tab: you and your friends ranked by total (top 20), refreshed on login when older than the configured hours
- History tab: players you searched, most kills first. Right-click to remove one, or clear them all
- Left-click a name for their top bosses (count set in config) and gains: today, this week, month and year
- Config toggles for what counts: PvM bosses, skilling bosses (Wintertodt, Tempoross, Zalcano), raids
- Right-click a player name (chat, friends list, players in the world) for "Boss lookup"

Gains come from the plugin's own lookups, so they start counting from the first time a player is looked up.

Bosses below the hiscore minimum (5 kills) aren't on the hiscores, so they don't count toward the total.
